# Sylip Corporation Sales Analysis

> A sales performance analysis for Sylip Corporation, a multi-category retailer (household items, groceries, and clothing), surfacing region-wise profit, annual revenue, and yearly units sold in an interactive Power BI dashboard.

**Tools:** `SQL Server` · `Power BI` · `Excel`
**Type:** Retail sales and profitability analysis
**Links:** [Interactive Power BI dashboard](https://app.powerbi.com/view?r=eyJrIjoiZWNkZjQ0MjItMjQzNy00Nzg3LWIzZDMtYmM2N2I3M2M1MGQ3IiwidCI6ImRmODY3OWNkLWE4MGUtNDVkOC05OWFjLWM4M2VkN2ZmOTVhMCJ9) · [SQL script](./Sylip%20Corporation%20Sales%20Analysis%20-%20SQL.sql)

## Overview
This project uses Sylip Corporation's retail sales data to give the business a clear view of performance across regions, products, and years. The work moves from raw data to decision-ready insight: Excel for initial handling, SQL Server for cleaning and transformation, and Power BI for the final interactive dashboard.

## What it delivers
- Region-wise profit, so the company can see where it makes and loses money.
- Annual revenue and yearly units sold, to track growth and demand over time.
- An interactive dashboard that lets stakeholders explore the KPIs and drill into performance.

## Approach
Store and prepare the sales data in Excel, clean and transform it in SQL Server, then model and visualize the KPIs in Power BI to support recommendations on where to focus for profitability.

## Skills demonstrated
Data manipulation and cleaning in SQL, KPI definition, and interactive dashboard design in Power BI.
